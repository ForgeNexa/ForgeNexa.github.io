Ecosystem Applications

Forge IDE

A fast, local-first code editor combining the Monaco Editor with a dedicated Go daemon for background workspace indexing, multi-tab layout, IntelliJ-style collapsible bottom panels, and Language Server Protocol (LSP) diagnostics.

  • Monaco code editor with multi-language syntax highlighting
  • Go daemon (forge-daemon) for AST analysis & file events
  • IntelliJ-inspired bottom panels: Terminal, Problems, Output
  • 100% local-first data storage with zero telemetry

Forge API

An interactive API client engineered for high-throughput testing and debugging. Powered by a high-concurrency Go execution engine with persistent connection pooling, sub-millisecond telemetry, and an intuitive React 19 workbench.

  • High-concurrency Go HTTP execution engine
  • DNS resolution, TLS handshake, and latency breakdown
  • Environment variables with AES-256 encrypted secrets
  • Export to cURL, Go, Python, and JavaScript snippets

Forge Terminal

A multiplexed terminal emulator delivering authentic pseudoterminal (PTY) sessions via a Go supervisor process. Featuring GPU-accelerated xterm.js rendering, horizontal and vertical pane splits, and robust lifecycle control.

  • Authentic OS PTY allocations using creack/pty
  • Flexible grid splitting with independent scrollback buffers
  • Process supervisor preventing orphaned background processes
  • Custom color themes and font ligatures support

Forge Git

A visual Git client built for speed and clarity. Features topological commit graph traversal, multi-file partial hunk staging, side-by-side visual diffs, and branch management without the bloat of web wrappers.

  • Real-time topological commit DAG visualization
  • Hunk-level staging and interactive diff viewer
  • Safe git operations powered by porcelain Go wrappers
  • Instant branch switching, stashing, and conflict detection

Forge Hub

The central mission-control application launcher for the ForgeNexa developer ecosystem. Auto-discovers installed Forge tools, scans workspace repositories, and orchestrates cross-tool workflows.

  • Automated $PATH binary detection for all Forge tools
  • Recent workspace and git project quick-switcher
  • Process status and daemon lifecycle telemetry
  • Centralized developer profile configuration

Forge Core

The shared Go systems foundation providing battle-tested concurrency primitives (bounded worker pools, graceful draining), cryptographic security (AES-256-GCM, path traversal defense), and atomic I/O.

  • Bounded concurrency worker pools with context cancellation
  • AES-256-GCM authenticated encryption for credential stores
  • SafePath validation preventing directory traversal attacks
  • Atomic file writes with automated fallback protection

Core Architectural Principles

1. Local-First & Private Your code, secrets, and telemetry stay on your machine. No mandatory accounts, no cloud sync lock-in, and zero background analytics tracking.
2. Go-First Performance Computationally intensive tasks — filesystem indexing, terminal multiplexing, HTTP execution, and git DAG traversal — run natively in Go.
3. Modular & Independent Each application operates completely independently as a standalone binary or cooperatively under Forge Hub.
4. 100% Open Source Released under permissive open-source licenses. Audit the source code, contribute features, and inspect every line on GitHub.
